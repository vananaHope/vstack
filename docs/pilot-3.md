## 관리자 실행에서 나온 것

- **Bash heredoc 함정**(인계 문서에 있던 것): 시범 준비에서 Python 치환이 `\\n` 변환으로 실패했다. 실패라 파일은 바뀌지 않았고 Edit 도구로 다시 했다.
- **콘솔 인코딩**: 보관 스크립트가 출력한 manifest의 한국어가 콘솔에서 깨져 보였다. 바이트로 확인하니 manifest는 정상 UTF-8이었다(`PYTHONIOENCODING=utf-8`로도 콘솔 표시는 그대로). 판정에는 영향이 없다.
- **명세 새 눈 점검**: OpenCode Go 계정이 막혀 서브에이전트로 했다. 질문 2개(텍스트 `list` 판정 방법, 비어 있는 `common-findings.md`)를 받아 반영했다.
- **Codex fast**: 끄는 조건 없음(7일 48%, 창 경과 90.5%), 켜는 조건 "묶음의 마지막"으로 켰다. 첫 응답 세션 기록에서 `service_tier=priority`를 확인했다.
- **걸린 시간**(측정): 구현 배정 00:16 → 병합 00:38. 작업자 실행 2번(Codex 구현 1, Claude review 1), 서브에이전트 1번.
- **한 세션 시범의 한계**: 버그를 심은 세션이 곧 고친 세션이라 진단은 맹검이 아니다. 갈래와 절차만 본 시범이다.
