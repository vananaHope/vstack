# vstack 사용 안내

vstack을 쓰는 사람을 위한 문서다. 처음 쓰는 사람은 위에서부터 차례로 읽는다. 규칙의 정본은 에이전트가 읽는 `skills/`의 실행 문서이고, 이 안내는 그것을 줄여 옮기고 링크를 건다. 둘이 다르면 실행 문서가 맞다.

| 문서 | 무엇을 다루나 |
| --- | --- |
| [first-run.md](first-run.md) | 설치부터 맡기기 한 번을 끝내기까지 |
| [concepts.md](concepts.md) | 갈래, 관리자와 작업자, 기준 브랜치, 계약과 병합 관문 |
| [delegate.md](delegate.md) | 맡기기: 한 단위의 일을 작업자에게 넘기기 |
| [orchestrate.md](orchestrate.md) | 지휘: 이슈 여러 개를 계약과 병합 관문으로 넘기기 |
| [feature-branch.md](feature-branch.md) | 기능 브랜치에서 지휘하고 PR 하나로 기본 브랜치에 넣기 |
| [settings.md](settings.md) | 프로젝트 설정의 절과 기본값 |
| [troubleshooting.md](troubleshooting.md) | 설치와 첫 실행에서 막히는 곳 |
| [migrate-from-agent-orchestra.md](migrate-from-agent-orchestra.md) | agent-orchestra를 쓰던 프로젝트에서 넘어오기 |

용어는 [GLOSSARY.md](../../GLOSSARY.md), 설계와 변경 이력은 [design.md](../design.md), 되돌리기 어려운 결정은 [docs/adr/](../adr/)에 있다. vstack 자체를 고치는 사람은 [CONTRIBUTING.md](../../CONTRIBUTING.md)를 본다.
