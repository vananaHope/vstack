- **O1 구현 작업자 시작**: Run·Task·Dispatch·worktree가 맞았다. 시작 HEAD는 기준 커밋이었다. `turnStart`는 `observed`였다(omp는 `unsupported`였다). 모델은 Opus였다: Orca의 실제 적용 모델 `opus`, 세션 기록의 모델 `claude-opus-5-5`(응답 37개 전부), 커밋 꼬리말 "Claude Opus 5.5".

- **O3 서브에이전트**: 부르지 않았다(세션 기록에 Agent 도구 호출 0, 곁가지 기록 0). 작업자는 시작 11초 뒤 `subagents.md`를 읽었고 완료 보고에 "서브에이전트: 없음"이라고 적었다. 파일 둘을 고치는 일이라 "쓰지 않는 때"에 맞다. **부르는 길(`Explore`, `sonnet`, 쓰기 없음)은 검증하지 못했다.**
- **O4 검토**: 검토자가 같은 worktree에서 돌았다. 맡길 때와 받은 뒤의 HEAD와 status가 같았다(이 대조는 Git이 무시하는 파일에 쓴 것과 고쳤다가 되돌린 것은 잡지 못한다). 보고서는 정한 경로에 있었고 결론, 수용 기준 판정표, 지적 목록, 범위 밖에서 본 것, 사람이 확인할 것이 있었다. 수용 기준을 직접 돌렸고, 다른 검증 시나리오 11개와 스스로 만든 입력(빈 문자열, `+1`, `1e0`, 전각 숫자 등)도 OS 임시 폴더에서 돌렸다.
- **O5 재검토**: 같은 검토자가 "보내기"로 받았다. 범위(이전 HEAD부터의 diff, 더한 수용 기준)를 지켰고 새 보고서 경로에 썼다.

- **O7 시간**: 첫 구현 약 2분 40초(질문과 답 포함), 구현 확인 약 25초, 첫 검토 약 2분, 후속 구현 약 1분 30초, 구현 확인 약 25초, 재검토 약 1분 50초, 마지막 확인 약 1분. 처음부터 끝까지 약 10분.
