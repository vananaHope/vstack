# 병합 관문은 vstack 관리자가 실행하는 병합에만 보장한다

지휘의 병합 관문(증거의 대상이 지금 원격 PR의 head·base와 같은가, 모든 증거가 보관됐는가)은 관리자가 병합 명령을 내리기 직전에 확인한다. 사람이 GitHub에서 직접 병합한 것은 막지 못한다. "병합됐어"를 들으면, 병합된 head를 마지막 관문 통과 기록의 `H`와 대조하고, 다르거나 기록이 없으면 "관문 미확인 병합"으로 보고한다(`skills/v-mode/contracts/merge-gate.md` "사람이 직접 병합한 경우"). 병합 전의 base 대조와 보관 확인은 사후에 다시 할 수 없다. 기준 브랜치는 그 병합으로 이미 움직였기 때문이다.

저장소의 필수 검사(required check)로 외부 관문을 거는 길은 첫 버전에서 하지 않았다. 저장소마다 설정이 필요하고 회사 저장소에서는 권한이 없을 수 있다.
