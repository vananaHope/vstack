# 관리자는 기록마다 하나이고, 다른 관리자의 기록은 겹침 판정에만 읽는다

[ADR 0011](0011-delegation-and-orchestration-boundary.md)과 [ADR 0013](0013-delegation-alongside-orchestration.md)은 "한 저장소의 관리자는 하나"라고 정했다. 0.26.0에서는 이 문장 때문에 다른 세션이 관리하는 맡기기가 있으면, 쓰는 곳과 검증 자원이 겹치지 않아도 지휘가 새 작업을 시작하지 못했다(2026-11-25 다른 저장소의 실제 지휘에서 막혔다). 이 결정은 그 문장을 "관리자는 기록마다 하나"로 바꾼다. 같은 메인 저장소에서 지휘 작업과 다른 세션이 관리하는 맡기기도, 맡기기와 다른 세션이 관리하는 지휘 작업도, 쓰는 곳과 검증 자원이 겹치지 않으면 함께 진행한다(2026-11-25 사용자 질문 "어차피 별도의 worktree로 하는데 막을 이유가 있어?"에 따른 판단. 병합은 사용자 승인).

막을 이유를 하나씩 봤다. 쓰는 곳은 worktree가 나뉘고 겹침 판정이 이미 본다. 검증 자원도 겹침 판정이 본다. 남는 것은 관리자가 하나라서 저절로 지켜지던 네 가지였다. 이것들은 시작을 막지 않고 아래 규칙으로 지킨다.

- **Run은 관리자 세션마다 따로다.** Orca의 `run-use`는 Run 하나만 남기므로, 다른 세션의 Run에 묶으면 두 관리자가 같은 Run의 메시지에 깨고, 앞선 관리자의 묶음이 어떻게 되는지는 확인하지 않았다. 그래서 다른 관리자의 기록에 적힌 Run에는 묶지 않는다. 같은 세션 안에서는 0.26.0대로 Run 하나를 함께 쓴다.
- **다른 관리자의 기록은 읽기만 한다.** 겹침 판정에 그 기록의 예정 쓰기 영역과 검증 자원을 읽는다. 그 기록을 고치거나, 그 작업자의 메시지를 처리하거나, 그 일의 다음 단계를 하지 않는다. 그렇게 하려면 0.26.0대로 그쪽 이어받기를 먼저 한다.
- **반영과 병합은 세션을 넘어서도 한 번에 하나다.** 한 관리자가 양쪽을 알 때는 저절로 지켜졌다. 이제는 반영·병합 직전에 다른 관리자의 기록을 읽어 그쪽이 반영·병합 도중이면 미룬다. 기준 브랜치가 움직이면 따라가는 규칙(맡기기의 기준 비교, 병합 관문의 rebase 행)은 그대로다.
- **이어받기는 Run 하나만 할 수 있다.** 이 세션이 자기 Run에 진행 중인 기록을 가진 채로 다른 Run의 기록을 이어받지 않는다. 그런 이어받기는 새 세션에서 한다.

지휘가 진행 중이면 맡기기를 로컬 `main`에 병합하지 않는다는 규칙(ADR 0013)은 관리자가 누구든 적용한다. 지휘 작업끼리는 바꾸지 않았다. 지휘를 시작하면 끝나지 않은 지휘 작업을 모두 이어받으므로 지휘의 관리자는 저장소에 하나다. 계약과 병합 관문은 바뀌지 않는다(`vstack-contract@5` 그대로).

**Considered Options**: 조항을 그대로 두고 사용자가 매번 예외를 정하게 하는 길은 버렸다. 실제로 막혔을 때 지휘가 내놓은 추천 선택지가 "새 Run으로 따로 돌리는 예외"였고, 그것이 위 규칙과 같다. 매번 예외로 두면 프로젝트마다 다르게 적힌다. 다른 세션의 Run에 함께 묶는 길도 버렸다. 메시지를 기록으로 나누는 일이 한 관리자를 전제하고, `run-use`를 두 세션이 함께 하는 동작은 Orca에서 확인하지 않았다. 반영·병합 순서를 저장소 전체 잠금으로 지키는 길도 생각했지만 버렸다. 기록의 상태(맡기기의 반영 기록, 지휘의 `병합 대기`)는 시작한 뒤에야 적혀 두 세션이 거의 같은 때 들어가는 것은 막지 못한다(PR 리뷰 지적). 그래도 그런 겹침은 드물고, 생기면 기준 비교와 rebase 행이 대부분 따라가므로 잠금과 남은 잠금 처리를 더할 만하지 않다고 사용자가 판단했다(2026-11-25).

**바뀜(2026-11-25)**: 셋째 문단의 "지휘 작업끼리는 바꾸지 않았다. 지휘의 관리자는 저장소에 하나다"는 [ADR 0015](0015-base-branch-per-orchestration.md)가 "지휘의 관리자는 기준 브랜치마다 하나"로 바꿨다. 같은 기준 브랜치에 들어가는 기록 사이의 규칙은 그대로다.

**돌려 보지 않았다.** 다른 세션의 맡기기와 지휘를 함께 진행한 시범은 아직 없다.
