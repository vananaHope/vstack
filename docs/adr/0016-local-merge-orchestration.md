# 지휘의 병합 위치를 고를 수 있게 하고, 로컬 병합에도 병합 관문을 그대로 둔다

0.28.0([ADR 0015](0015-base-branch-per-orchestration.md))으로 지휘는 기능 브랜치 `A`를 기준 브랜치로 삼게 됐다. 하지만 이슈마다 PR을 열어 원격 `A`로 병합했으므로 `A`가 원격에 있어야 했다. 사용자가 실제로 일해 온 방식은 다르다. `A`를 push하지 않고 이슈 결과를 로컬에서 `A`에 모은 뒤, 마지막에 `A`→기본 브랜치 PR 하나만 원격에 올려 병합한다(2026-11-25 사용자 설명). vstack 전의 agent-orchestra와 pstack도 PR로 병합했지만 기준이 늘 원격에 있는 기본 브랜치였으므로 이 조건이 드러나지 않았다.

그래서 프로젝트 설정 "병합" 절에 **병합 위치**(`원격` / `로컬`)를 둔다. 기본은 `원격`이고 지금과 같다. `로컬`은 기준 브랜치가 기본 브랜치가 아닐 때만 쓴다. 기본 브랜치에 들어가는 길은 늘 PR로 남긴다(사용자 결정: 설정으로 고르고 기본은 PR).

`로컬`에서도 병합 관문(G1~G5)은 그대로다. 판정식은 증거와 검토만 보므로 원격이 없어도 성립한다. 원격에 기대던 두 곳만 바꾼다.

- **대상 읽기**: `H`는 작업 브랜치, `B`는 로컬 기준 브랜치에서 읽는다.
- **병합 명령과 확인**: 관리자가 기준 브랜치가 체크아웃된 곳에서 `merge --no-ff` 또는 `merge --squash`로 병합한다. 병합 직전에 `H`·`B`를 다시 읽어 판정한 값과 같을 때만 병합한다. 이것이 `--match-head-commit`을 대신한다. 병합 뒤에는 새 커밋의 첫 부모가 `B`이고 트리가 `git merge-tree --write-tree B H`와 같은지 본다. 원격의 기준 브랜치 경쟁 확인과 같은 확인이고, 같은 이유로 잠금은 두지 않는다. `rebase` 방법은 커밋 하나로 확인할 수 없어 쓰지 않는다.

계약을 바꾸므로 `vstack-contract@6`으로 올렸다(`merge-gate.md` "로컬 병합", `state-and-rollback.md`의 게시 절과 관문 결과).

`로컬`이면 0.26.0([ADR 0013](0013-delegation-alongside-orchestration.md))의 두 규칙이 바뀐다.

- **로컬 기준 브랜치의 커밋 확인**: 원격과 견주던 "push하지 않은 커밋이 없다"는 "기록되지 않은 커밋이 없다"가 된다. 기본 브랜치와 갈라진 뒤의 첫 부모 커밋이 모두 관문 기록의 병합 커밋, 맡기기 반영 기록의 통합 SHA, 8단계에서 기본 브랜치를 받은 병합 커밋 가운데 하나여야 한다. 사용자가 기준 브랜치에 직접 한 커밋은 알리고 멈춘다.
- **맡기기의 로컬 병합**: 이슈 PR이 없으므로 맡기기 병합이 이슈 PR에 실려 나가지 않는다. 그래서 지휘 중에도 맡기기를 그 지휘의 기준 브랜치에 로컬 병합해도 된다. 위 확인이 반영 기록의 통합 SHA로 그것을 가린다. 그래서 반영은 커밋 하나(`--no-ff` 병합이나 squash)로 하고 fast-forward와 rebase는 쓰지 않는다.

**잃는 것.** 이슈마다의 PR 기록, PR에서 받는 사람의 리뷰와 "리뷰 반영해", 이슈마다 도는 원격 검사, 진행 중인 작업의 원격 백업. 대신 병합 커밋 메시지 본문에 PR 양식 본문을 적고, 8단계 PR 본문에 이슈마다 `H`, 병합 커밋, 관문 기록, 검토 결론을 모은다. 사람의 리뷰는 8단계 PR에서 한 번 받는다.

**Considered Options**: 기준 브랜치의 첫 게시만 자동으로 하는 길이 있었다. 계약은 그대로지만 사용자의 방식(원격에 올리지 않고 모음)과 맞지 않는다. `로컬`을 기준 브랜치가 기본 브랜치가 아닐 때의 기본값으로 두는 길도 있었다. 사용자는 기본을 PR로 두고 설정으로 고르기로 했다. 로컬 병합을 기본 브랜치에도 허용하는 길은 버렸다. 기본 브랜치에 들어가는 변경이 PR 없이 원격에 나가게 된다. 병합을 `git update-ref`의 기대값 비교로 원자적으로 하는 길은 체크아웃된 작업 트리를 따로 맞춰야 해서 두지 않았다.

**돌려 보지 않았다.** 로컬 병합으로 지휘한 시범은 아직 없다.
